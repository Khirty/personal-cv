## Deploy with Vercel

1. Create a **public** GitHub repository, for example `personal-cv`.
2. Commit and push the website files to the repository.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. For this static HTML site, select **Other** if asked for a framework; leave build command empty and use the repository root as the root directory.
5. Click **Deploy**, open the generated URL, and verify all sections and links.
6. Replace the placeholder URL in this README and commit that change.
